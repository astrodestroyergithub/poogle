# Poogle — Unified Ecosystem Web Application (Netlify Ready)

**Developer Credit:** Created & Engineered by **Mr. Doo-doo**

## Overview
**Poogle** is a pixel-faithful, fully responsive clone of the Google application designed for zero-configuration deployment on **Netlify**. It integrates four complete sub-platforms inside the parent website:

1. **Poogle Stool** *(Google Cloud Clone)*: Available on Google Cloud for enterprise developers and builders. Includes the Cloud Overview Dashboard, Vertex AI Model Garden, Enterprise API Key manager, and interactive Cloud Shell terminal.
2. **Poogle Poop** *(Google Antigravity Clone)*: Available for Google AI Ultra subscribers inside Poogle's agentic development platform (standalone or via Android Studio Canary). Includes multi-agent mission control, multi-file code editor with diff acceptance, and a live Android Canary Emulator preview.
3. **Shitmini App & Search** *(Gemini App & Search Clone)*: Available for Google AI Pro and Ultra subscribers inside the Shitmini app and AI Mode in Search.
4. **Poogle Crap** *(Google Chrome Clone)*: Accessible directly inside Chrome for quick queries via the `@shitmini` omnibox address bar, multi-tab browser workspace, AI Side Panel, and DevTools inspect drawer.

## Deploying to Netlify
1. **Drag & Drop**: Unzip `poogle-netlify-bundle.zip` and drag the folder directly into [Netlify Drop](https://app.netlify.com/drop).
2. **Git / CLI Deploy**: Push the files to a repository or run `netlify deploy --prod --dir=.`. `netlify.toml` and `_redirects` are pre-configured.
